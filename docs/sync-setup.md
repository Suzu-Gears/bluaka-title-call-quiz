# クラウド同期のセットアップ手順

進捗のクラウド同期は「同期コード」方式です。サーバーは Google Apps Script (GAS) の
ウェブアプリで、Google スプレッドシートを保存先として使います。
アカウント登録は不要で、同期コード (UUID v4) が実質パスワードになります。

保存先は 2 通りあります。

| 方式 | 保存先 | 必要な作業 |
| ---- | ------ | ---------- |
| 既定 | 作者のスプレッドシート | 何もしなくてよい（同期コードを発行するだけ） |
| 自分のシート | 自分の Google アカウントのスプレッドシート | この文書の「手順B」（5〜10分） |

どちらの場合も、同期はベストエフォートです。正本は常に端末内のデータと
エクスポート機能なので、大事な記録は時々エクスポートしておいてください。

---

## 手順A: 管理者向け — 既定の保存先（中央シート）を用意する

サイトの管理者が一度だけ行う作業です。全利用者の進捗が、この 1 枚のシートに
同期コードごとの行として保存されます。

1. Google スプレッドシートを新規作成する
2. メニューの「拡張機能 > Apps Script」を開き、
   [`docs/spreadsheet-sync.gs`](./spreadsheet-sync.gs) の内容を貼り付けて保存する
3. 「デプロイ > 新しいデプロイ > 種類: ウェブアプリ」を選び、次の設定でデプロイする
   - **次のユーザーとして実行: 自分**
   - **アクセスできるユーザー: 全員**
4. 初回デプロイ時に承認画面が出る。「このアプリは Google で確認されていません」と
   表示されたら「詳細」→「（プロジェクト名）に移動」で承認する
   （自分が作ったスクリプトを自分で承認しているだけなので問題ない）
5. 発行された `https://script.google.com/macros/s/…/exec` の URL を
   `.env` の `VITE_SYNC_ENDPOINT` に設定してビルド・デプロイする

```
VITE_SYNC_ENDPOINT=https://script.google.com/macros/s/XXXX/exec
```

これで全利用者のクイズ画面メニューに「クラウド同期」が現れ、
何も設定しなければこのシートに保存されます。

### 運用メモ

- シートには `syncCode | updatedAt | json` の 3 列で 1 人 1 行が並ぶ。
  中身はクイズの成績だけで、個人を特定できる情報は含まれない
- GAS の無料枠は 1 日あたり 2 万実行程度。保存はクイズ終了時と手動操作時のみ
  なので、通常の利用で枯渇することはまず無い
- コードを修正したら「デプロイ > デプロイを管理」から既存デプロイを
  **編集して新バージョンを発行**する（新しいデプロイを作ると URL が変わってしまう）

## 手順B: 利用者向け — 自分のスプレッドシートに保存する

進捗を自分の Google アカウント内に置きたい人向けです。
自分専用の保存先を作って、その URL をクイズの設定に貼り付けます。

### 1. スプレッドシートとスクリプトを用意する

**テンプレートをコピーする場合（推奨）:**

1. 配布されているテンプレートのスプレッドシートを開く
   （テンプレート URL: ※公開時に記載）
2. メニューの「ファイル > コピーを作成」で自分の Google ドライブにコピーする
   （シートに紐づいたスクリプトも一緒にコピーされます）

**手動で作る場合:**

1. Google スプレッドシートを新規作成する
2. メニューの「拡張機能 > Apps Script」を開く
3. [`docs/spreadsheet-sync.gs`](./spreadsheet-sync.gs) の内容を全部コピーして、
   エディタに貼り付けて保存する（元からある `function myFunction()...` は消してよい）

### 2. ウェブアプリとしてデプロイする

1. Apps Script のエディタ右上の「デプロイ > 新しいデプロイ」を押す
2. 歯車アイコンから種類「**ウェブアプリ**」を選ぶ
3. 次のとおり設定して「デプロイ」を押す
   - **次のユーザーとして実行: 自分**
   - **アクセスできるユーザー: 全員**
4. 「アクセスを承認」を求められたら自分の Google アカウントを選ぶ
5. 「このアプリは Google で確認されていません」という警告画面が出たら、
   左下の「**詳細**」→「**（プロジェクト名）（安全ではないページ）に移動**」を押して許可する

   > この警告は「Google の審査を受けていない自作スクリプト」すべてに出るものです。
   > いま許可しようとしているのは、自分のドライブにある自分のスクリプトに、
   > 自分のシートへの書き込みを許すことだけです。

6. 発行された **`https://script.google.com/macros/s/…/exec`** の URL をコピーする

「アクセスできるユーザー: 全員」にしても、シート自体が公開されるわけではありません。
この URL と同期コードの両方を知らない限り、他人はデータに触れません。

### 3. クイズ側に保存先を設定する

1. クイズ画面のメニューから「クラウド同期」を開く
2. 「**保存先URL**」欄に、コピーした `/exec` の URL を貼り付ける
3. 同期コードが未発行なら「新しいコードを発行」を押す
4. 「クラウドへ保存」で動作確認する。スプレッドシートに `progress` シートが
   自動で作られ、1 行増えていれば成功

別の端末でも同期したい場合は、その端末でも同じ「保存先URL」と「同期コード」を
入力してください。保存先URL欄を空欄に戻すと、既定（作者のシート）に戻ります。

### 困ったとき

- **同期コードを失くした** … クラウド側のデータには到達できなくなります。
  端末に進捗が残っていれば、新しいコードを発行して保存し直してください
- **URL を貼っても失敗する** … コピーしたのが `/exec` で終わる URL か確認して
  ください（`/dev` で終わる URL はエディタ専用で、他人からはアクセスできません）
- **スクリプトを更新したい** … リポジトリの `docs/spreadsheet-sync.gs` を貼り直し、
  「デプロイ > デプロイを管理」から既存デプロイの新バージョンを発行してください
  （新しいデプロイを作ると URL が変わるので、クイズ側の再設定が必要になります）
